# 枪包文本源码

公开版本：**1.1.47**。枪械、配件、显示、语言、配方、Lua/JS、shader、模型和动画JSON收录在 [完整源码归档](../mods/SSJJRPG-1.1.47-source.zip) 中，解压后查看 `tacz/`；模组独有资源和43个资源生成脚本位于 `mods/`，配置模板位于 `config/` 与 `defaultconfigs/`。

424项枪包文本和27项模组独有资产与同版Release对应成员逐字节一致。186份生成的粒子/网格/骨骼采样以及图片、音频等素材在[Release配对运行包](https://github.com/Vo1terEn/tacz-ssjj/releases/tag/v1.1.47)中完整保留；完整路径、原始/公开成员SHA和获取位置见归档内 `tacz/source-manifest.json`。

源码归档不是可直接安装的枪包。修改时按包内路径覆盖同版运行资源；外部原始素材和提取环境不随归档分发。GPL-3.0的原黯水晶资源与技能例外继续有效，其他美术素材不因JSON文本形式而改用MIT。
