# 枪包文本源码

公开版本 **1.1.49**。这里提供当前运行包的枪械、配件、配方、语言、显示、Lua/JS、shader及非采样模型/动画JSON。模组独有文本在`../mods/resources/`，配置模板在仓库`config/`与`defaultconfigs/`。

图片、音频和生成的原生粒子/网格/骨骼数据保留在[同版Release](https://github.com/Vo1terEn/tacz-ssjj/releases/tag/v1.1.49)，本目录不能直接作为完整枪包安装。源码与版本化Release资源逐字节对应，见source-manifest.json。资源JSON的文本形式不改变原素材许可。
