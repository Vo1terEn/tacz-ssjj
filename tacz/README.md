# 枪包文本源码

公开版本：**1.1.48**。本目录直接提供枪械、配件、显示、语言、配方、Lua/JS、shader、模型与动画 JSON 的可浏览文本源码。模组独有文本资源放在 `../mods/resources/`；配置模板在仓库 `config/` 和 `defaultconfigs/`。

按包内路径覆盖同版 Release 枪包。这里不包含图片、音频及生成的粒子/骨骼/网格采样，不能作为独立安装枪包；完整运行资源见[同版 Release](https://github.com/Vo1terEn/tacz-ssjj/releases/tag/v1.1.48)。逐文件原始与公开 SHA、来源及元数据归一化字段见 [source-manifest.json](source-manifest.json)。

美术、模型与原游戏素材保留原权利，原黯水晶资源与技能的 GPL-3.0 许可继续有效；不因文件是 JSON 而统一改用 MIT。资源生成脚本位于 `../mods/tools/resource-generation/`，需要清单列出的原始外部素材和制作环境。
