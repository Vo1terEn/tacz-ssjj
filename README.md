# [SSJJRPG] 生死狙击冒险枪包

当前公开版本：**1.1.48**。Minecraft **1.20.1** / Forge **47.4.16** 或已核验的 **47.4.28** / TaCZ **1.2.0**，保留 **1.1.8-hotfix2** 的离线兼容路径。

- [完整安装包、配对模组与枪包](https://github.com/Vo1terEn/tacz-ssjj/releases/tag/v1.1.48)
- [Java 源码与制作链](mods/README.md)、[枪包文本源码](tacz/README.md)
- [配置模板](config/ssjjrpg.toml)、[默认服务器配置](defaultconfigs/ssjj_dark-server.toml)
- [运行产物校验](SHA256SUMS)、[来源与公开副本清单](source-manifest.json)、[运行包核验记录](runtime-manifest.json)

本版修复 GunsmithLib 的枪械说明框 Mixin 注入失败：保留 TaCZ 原有 `List.subList` 调用，仅调整本包指定武器的说明行数上界，使 GunsmithLib 可以继续包装原调用。针对他人报告中神化/诸神黄昏组合的启动崩溃进行了定位与兼容验证；未新增对这些可选模组的硬依赖。

修正本包误设的 Forge 47.4.28 最低限制，将本方声明下限改为 **47.4.16**。本版还纳入此前本地交付中的次元过载伤害结算修正与粒子插值共用实现；来源清单记录对应 Java 增量与 ASM 步骤。

使用 **GunsmithLib 7 / 诸神黄昏 8** 时必须搭配 **TaCZ 1.2.0**。Cloth Config 是可选配置界面依赖，第三方前置不包含在本安装包中。

## 安装

1. 安装 Minecraft、Forge 和 TaCZ 前置，退出游戏并备份原文件。
2. 解压 `SSJJRPG-1.1.48-MC1.20.1.zip`，将其中 `mods/` 与 `tacz/` 成对替换；也可分别下载同版 JAR 和 gunpack ZIP。不要保留重复的旧模组或旧枪包。
3. 新安装可使用配置模板；已有自定义配置时保留原值。开房端和加入端均需更新。

完整安装 ZIP 需要先解压。本次发布没有自动安装或启动游戏。

## 验证与源码边界

本地兼容版本已通过真实 Forge 47.4.16 / 47.4.28 加载器的元数据与依赖排序校验；663 个类的 API 链接、16 份核心脚本的组合变换，以及 TaCZ 1.2.0 / 1.1.8-hotfix2 两条路径检查通过。GunsmithLib 兼容修复通过实际 Mixin 注入回归和说明行数行为检查。这些是已测本地代码的离线结果，公开副本通过 class、脚本字节一致性继承，具体范围见清单。

公开运行副本从本地交付安全重打包，本轮统一版本元数据，并更新枪包内两份过时安装说明、去除其中的本机路径；运行代码、核心脚本和玩法资源保持原字节。发布时检查版本、JSON/TOML 解析、ZIP CRC、SHA256 与配对资源一致性。**没有全量重新编译模组，也没有新增完整游戏、GPU 或联机实测。**

Java 制作链包含作者历史快照、可编辑增量、名称映射和 ASM 修改。来源清单区分历史快照与当前已匹配代码，不能把类名对应当成完整方法体一致；目前仍不是可独立一键全量重建的 Gradle 工程。大型运行素材保存在同版 Release 的配对运行包中。
