## 安装

1. 安装上述Minecraft、Forge与TaCZ依赖，退出游戏/停止服务器并备份原文件。
2. 下载 `SSJJRPG-1.1.47-MC1.20.1.zip` 并解压，将其中 `mods/` 与 `tacz/` 成对替换；不要保留多份旧SSJJRPG模组或枪包。也可下载同版JAR和gunpack ZIP分别安装。
3. 新安装可使用配置模板；已有 `config/ssjjrpg.toml` 时保留自己的配置值。开房端和加入端均需更新并重新启动。

完整安装ZIP不能直接放进 `tacz/`。本次发布流程没有自动安装或操作游戏实例。

## 源码与构建边界

源码整理副本保留包路径、来源记录与SHA256；本次可用的登录通道是GitHub网页，目录上传未受支持，因此按实际网页限制提供源码归档，另公开可浏览的说明与清单。生成的逐帧网格/粒子采样、图片、音频等运行素材在同版Release枪包中完整保留，不重复放入Git源码归档。

Java制作链由历史源码快照、增量编译、运行时映射和ASM补丁组成，**尚非完整、可独立一键重建的Gradle工程**。源码清单区分当前成品已逐字节匹配的编译来源、补丁前基线及仅类名对应的历史快照；不能把类名覆盖率当作全部方法与成品一致。历史源码归档仍可从旧tag取得。

本次公开运行副本从已验证交付重打包，只统一版本元数据并规范少量纯溯源字段中的本机路径；所有class和脚本保持原字节。核验通过版本、JSON/TOML解析、ZIP CRC、SHA256、包内回读和1188项共有资源一致性。原开发版本的离线检查结果按相同字节继承，**没有新增完整游戏、GPU或双人联机实测，也没有宣称重新编译整个模组**。
