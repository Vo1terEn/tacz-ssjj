# 资源生成工具来源

这里保留当前资源制作链使用的原始转换/组装脚本：次元模型与皮肤导入、原生粒子采样与领域/标记/替身特效、专属配件与显示资源、寄生者原生模型/动画/特效、黯水晶身体及刀光资源、裁决原生身体/世界/皮肤效果、天罚枪口和皮肤资源。路径按原制作工作区保留，以便识别脚本间的引用，不包含历史预览、QA夹具、日志或生成的运行时素材。

这不是可独立一键重建资源的工具包。脚本依赖原游戏导出的素材、伴随脚本、原制作目录、同版基线，以及Python和部分原始Java映射制作链；这些提取资产/本机运行时未重新打包。完整生成采样保留在同版 Release 的原成员路径；`tacz/source-manifest.json` 列出入库文本的来源与校验，另汇总未入库的素材类别。使用发行版不需要重新提取素材。

公开副本只把本机字体、运行时依赖和addon_build绝对路径改为环境选项，未改转换算法。可选环境变量：`SSJJ_FONT_YAHEI`、`SSJJ_FONT_ARIAL`、`SSJJ_MODS_DIR`、`SSJJ_LIBRARIES`、`SSJJ_ADDON_BUILD`；使用相关脚本前按自己的环境配置。未指定时的相对fallback仅用于说明输入位置。完整原始/公开SHA256及修改字段见 `source-manifest.json`。这些公开副本仅做语法和归档对应核验，未声称在独立环境重跑全部素材生成链。

源码许可遵循仓库及已有例外；黯水晶原始资源和技能代码的GPL-3.0声明继续保留。工具引用的其他原始模型、美术、音频和动画不因源码公开而重新许可。此目录不附送这些原始第三方资产。
