# Java源码与制作链

公开版本：**1.1.47**。下载 [完整源码归档](SSJJRPG-1.1.47-source.zip) 后解压；保留 `mods/src/` 包路径、ASM补丁、coremod、资源生成工具，以及 `tacz/` 文本源码和配置模板。校验见 [SSJJRPG-1.1.47-source.zip.sha256](SSJJRPG-1.1.47-source.zip.sha256)。

源码中有292个顶层类名对应的作者快照：46个外部类字节匹配当前产物，6个匹配已知ASM修改前的产物，其余240个仅有类名对应（含208个继承历史作者源码）。**不是完整当前源码重建，也不能独立一键构建全部模组。** 已知ASM步骤、来源和逐文件原始/公开SHA见解压后的 `mods/README.md` 和 `mods/source-manifest.json`。

当前已授权通道仅为GitHub网页，实际目录上传不受支持，因此以保留目录的归档提供源码；没有把二进制或夹具充当源码。所有class、生成素材及依赖所需的同版运行包在[Release](https://github.com/Vo1terEn/tacz-ssjj/releases/tag/v1.1.47)。
